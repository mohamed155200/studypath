# StudyPath

مخطط مذاكرة جامعي بالعربي (PWA): حساب المعدل التراكمي، خطة المذاكرة، الامتحانات، المحاضرات، جلسات التركيز.

## التشغيل على GitHub Pages
1. ارفع كل الملفات في جذر المستودع (index.html في الجذر).
2. من **Settings → Pages**: Source = `Deploy from a branch`، Branch = `main`، Folder = `/ (root)`.
3. بعد دقيقة هيظهر الرابط: `https://USERNAME.github.io/REPO/`.

## تثبيت على الموبايل
- أندرويد (كروم): القائمة ← تثبيت التطبيق.
- آيفون (سفاري): مشاركة ← إضافة إلى الشاشة الرئيسية.
- لعمل APK: ادخل على pwabuilder.com بالرابط أعلاه.

## الذكاء الاصطناعي (اختياري)
من الإعدادات داخل التطبيق:
- **مفتاح Gemini API**: مفتاح مجاني من aistudio.google.com. بيتخزن على جهازك فقط ولا يدخل في النسخ الاحتياطي.
- **موديل Gemini**: سيبه فاضي للافتراضي (`gemini-flash-latest`) أو اكتب اسم موديل متاح عندك.
- **رابط Worker (بديل)**: لو عايز تستخدم Cloudflare Workers AI، انشر `worker/worker.js` وحط رابطه.

الأولوية: Claude (لو شغال جواه) ← مفتاح Gemini ← رابط Worker.

> لا ترفع مفتاح API في أي ملف على GitHub. المفتاح بيتكتب من الإعدادات فقط.

## التحديث
غيّر رقم الإصدار في `sw.js` (`studypath-vN`) مع كل نسخة جديدة عشان الكاش القديم يتمسح.
